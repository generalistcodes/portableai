PortableAI Windows package

This .exe is a PyInstaller one-file build of the Python UI. It is not a
signed installer; SmartScreen will warn.

What works
- Vendored Ollama. src/ollama_runtime.py downloads the GitHub
  ollama-windows-amd64.zip (standalone ollama.exe at the zip root plus
  lib/ollama/ DLLs — not OllamaSetup.exe) and launches `ollama serve`
  the same way as Linux/macOS.
- LAN IP detection for phone pairing. ui/server.py's _enumerate_lan_ips
  has a Windows `ipconfig` branch alongside Linux (`ip` / `hostname -I`)
  and macOS (`ifconfig` / `ipconfig getifaddr`).

What is still incomplete
- No Authenticode signature, no Inno/MSI installer.
